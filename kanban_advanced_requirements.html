Board-level navigation & interactions Board
Column management
  • Add column — klik "+ Add column" di ujung kanan board
  • Rename column — double-click header column → inline edit
  • Reorder column — drag header column ke posisi baru
  • Delete column — hover header → ⋯ menu → Delete (konfirmasi jika ada card)
  • Column color — pilih warna accent dari color picker
  • Column limit (WIP) — set max card per column, overflow highlight merah
  • Collapse column — klik chevron header → lipat jadi bar vertikal sempit
Drag & drop mechanics
  • Card drag antar column — otomatis update status
  • Card reorder dalam column — drag up/down ubah urutan/prioritas
  • Multi-select drag — shift+klik beberapa card → drag sekaligus
  • Drag preview — ghost card semi-transparent saat drag
  • Drop zone highlight — column glow + gap indicator saat hover
  • Undo drop — Ctrl+Z kembalikan posisi sebelumnya
  • Keyboard drag — Space pick card, arrow keys pindah, Space drop
Filter & grouping
  • Filter by assignee — multi-select, dim card yang tidak match
  • Filter by label/tag — AND/OR mode
  • Filter by due date — overdue, this week, this month
  • Filter by priority — urgent / high / medium / low
  • Search card — real-time highlight by title/description
  • Group by — switcher: Status / Assignee / Priority / Label / Date
  • Active filter chip — ditampilkan di toolbar, bisa dismiss satu-satu
View controls
  • Zoom level — compact / normal / comfortable card size
  • Hide empty columns — toggle dari board settings
  • Card fields visibility — pilih field mana yang muncul di card preview
  • Board vs Table toggle — switch ke table view tanpa pindah halaman
  • Timeline/Gantt toggle — switch ke timeline jika ada due date
  • Fullscreen mode — hide sidebar, expand board
  • Save view preset — simpan kombinasi filter+grouping sebagai named view
Card quick actions (tanpa buka detail) Card
Hover state actions
  • Quick assignee — avatar picker muncul saat hover kanan atas card
  • Quick priority — flag icon → pilih priority inline
  • Quick due date — date badge → mini calendar popover
  • Card menu (⋯) — Edit, Duplicate, Move to, Copy link, Delete
  • Drag handle — muncul di kiri card saat hover
  • Mark complete — checkbox di kiri atas, klik langsung selesai
Multi-select bulk actions
  • Select mode — Shift+klik atau checkbox mode dari toolbar
  • Bulk move — pindah semua card terpilih ke column lain
  • Bulk assign — set assignee ke semua selected cards
  • Bulk label — tambah/hapus label dari selection
  • Bulk due date — set due date sekaligus
  • Bulk delete — konfirmasi dialog sebelum eksekusi
  • Bulk archive — sembunyikan card dari board tanpa hapus

Header & properties panel
  • Title — klik langsung edit, auto-save on blur
  • Status dropdown — pilih column tujuan, card pindah di board
  • Assignee(s) — multi-assignee, avatar + nama, searchable
  • Priority — Urgent / High / Medium / Low + None
  • Due date — date picker + optional time, countdown badge
  • Labels/Tags — multi-select, color-coded, creatable inline
  • Parent / Epic link — tautkan ke card/epic lain
  • Custom fields — Number, Text, URL, Select, Date, Checkbox, Person
  • Story points / Estimate — field numerik untuk sprint planning
Rich text description
  • Block editor — Notion-style slash command (/) untuk insert block
  • Heading, paragraph, divider — basic text blocks
  • Bulleted & numbered list — termasuk nested list
  • Checklist/To-do — progress shown di card preview (3/5 ✓)
  • Code block — syntax highlight, copy button
  • Table block — inline table dengan add row/col
  • Image & file embed — drag drop atau paste langsung
  • Mention (@user) — trigger notifikasi ke user yang disebut
  • Card link embed (/card) — embed preview card lain inline
Attachments
  • Upload file — drag drop, paste, atau browse, multi-file
  • Image preview — thumbnail grid, klik lightbox
  • Document preview — inline untuk PDF, office files
  • External link attach — URL unfurl jadi preview card
  • Version/rename/delete — per attachment actions
  • Attachment count — badge di card preview board
Activity & comments
  • Comment thread — reply, mention, emoji react
  • Rich comment — bold, italic, code, list dalam comment
  • Edit / delete comment — dengan history label "edited"
  • Activity log — semua perubahan field tercatat otomatis
  • Toggle activity/comments — filter tampilan tab
  • Notification subscribe — watch card → dapat notif semua update
  • Resolve comment — collapse resolved threads
Relationships & dependencies
  • Linked cards — "blocks / blocked by / related to / duplicate of"
  • Sub-tasks — card anak, nested hierarchy, progress roll-up ke parent
  • Epic/parent link — attach ke epic atau initiative lebih besar
  • External issue link — link ke Jira, GitHub Issue, Notion page
  • Dependency warning — highlight jika blocked card sudah overdue
Time tracking
  • Estimate vs actual — input estimate, log actual time
  • Timer — start/stop timer langsung dari card detail
  • Manual log — tambah entri waktu manual dengan deskripsi
  • Time log history — list entri per user
  • Progress bar — estimate vs logged time visualisasi
Automation & advanced UX Automation
Automation rules
  • When card moved → assign user
  • When due date passed → move to Overdue
  • When label added → notify Slack/email
  • When all subtasks done → move parent
  • Recurring card creation (sprint reset)
Notifications
  • Assigned to card → in-app + email
  • Comment mention → instant notif
  • Due date reminder (1d, 1h before)
  • Card moved oleh orang lain → notif
  • Notification center dengan mark all read
Templates
  • Card template — prefilled fields + description
  • Board template — set kolom + automasi default
  • Save existing card as template
  • Template gallery per kategori proyek
History & versioning
  • Full field change log per card
  • Description version history (diff view)
  • Restore ke versi sebelumnya
  • Archive card (soft delete, recoverable)
Analytics / reporting
  • Cycle time per card (created → done)
  • Throughput chart per sprint/minggu
  • WIP violations history
  • Cumulative flow diagram per board
Keyboard shortcuts
  • N — new card di column aktif
  • E — edit card yang di-hover
  • F — focus search/filter bar
  • ← → — navigasi antar column
  • Esc — close detail panel / deselect
